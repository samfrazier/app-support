App Support

TwoRun Support

Email support@thatsfrazy.com. Include your device model, operating system version, and what happened.

If you have a GitHub account, you can also report an issue on GitHub. GitHub reports are public, so leave out personal information.

How to play

Enter a nickname, pick a pace, and tap RUN IT. Drag horizontally to steer. Match a ball with the same number to double yours. Red obstacles reduce your number.

On Medium, Hard, and Insane, swipe up to jump barriers. On Insane, jump gaps too.

Saved scores

Completed scores appear on your device’s leaderboard. If a save fails, check available storage and tap Retry Save.
